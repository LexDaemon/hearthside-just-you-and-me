# Teaching

## Use when
Use to teach a concept or skill through explanation, guided practice, and feedback. Use the included `anki` for card creation. For legal drills, work from supplied or verified sources without assuming jurisdiction. For a requested persistent corpus, agree on its files and use the available file tools; `qmd` can index it after its setup, but no absent skill is required.

## Procedure
1. Identify the learner's goal, current understanding, constraints, and evidence of progress.
2. Explain the smallest useful concept in plain language.
3. Ask for an attempt, prediction, or application before giving the next layer.
4. Correct the specific misconception and increase difficulty only after success.
5. End with a retrieval prompt and a next practice action.

## Output
Return a short lesson, practice prompt, feedback, and mastery check.

## Boundaries
Do not replace the learner's work, create persistent course files by default, or perform practical tasks that the learner should practise safely.
