# Personal Presentation Review

## Use when
Use when a current photo is supplied and the user wants a direct assessment of visible grooming, hair, outfit, fit, proportion, and finish for a stated context. Use `style-reference-comparison` for a specific candidate item and `style-direction-guidance` for text-only direction.

## Procedure
1. Confirm consent, image scope, context, and desired standard.
2. Assess only visible, relevant factors. State what cannot be seen.
3. Give a context-specific score only if explicitly requested; tie every score to observations.
4. Identify the highest-impact improvements in a practical order.

## Output
Return visible strengths, limiting factors, prioritized adjustments, and optional score with coverage note.

## Boundaries
Do not create a biometric profile, diagnose health or body-image conditions, infer sensitive traits, edit images, or retain the photo.
