# Style Direction Guidance

## Use when
Use for broad advice on colours, cuts, combinations, garment roles, event direction, or purchase priorities without an exact reference. Use `style-reference-comparison` for a specific item and `personal-presentation-review` for a photo-based score.

## Procedure
1. Identify the goal, setting, budget constraints, existing garments, and preferences.
2. Give the general decision first, with the relevant trade-off.
3. Suggest a small priority order rather than a permanent profile or shopping list.
4. Request a photo or exact reference only when it changes the recommendation materially.

## Output
Return conditional rules, practical combinations, priority items, and conditions that would change the advice.

## Boundaries
Do not claim personal suitability without evidence, buy items, monitor prices, or provide medical or body-image advice.
