# Text-first style decision guide

This reference turns broad questions into practical, conditional advice without pretending to see the user or a product that was never supplied.

## Colour

State the role first: neutral/base, low-contrast accompaniment, deliberate accent, or high-contrast statement. Then name the trade-off: intensity, warmth/coolness as it appears, pattern interaction, shine, formality, and the colours it must work beside. A current photo or product image becomes necessary only when personal contrast or exact hue determines the verdict.

## Cut and silhouette

Explain what the cut changes visibly: structure versus softness, width versus length, layer bulk, horizontal breaks, collar/neckline, trouser rise, hem, and movement. Do not turn body-shape taxonomies into rules; identify the effect and give the user a testable fit check.

## Purchase priority

A garment ranks higher when it:

1. solves a recurring real context;
2. combines with several items already owned by the user;
3. replaces a failing essential;
4. fits budget, comfort, weather, and maintenance tolerance.

It ranks lower when it duplicates an existing role, demands companion purchases, serves an unrealistic occasion, or creates care friction the user is unlikely to accept.

Always offer the no-buy branch: combine, alter, repair, or wait for a better-defined need.

## Local context

Use season, city, heat/rain, availability, price, and urban formality only when they materially affect the decision. Ask for the relevant location when climate, local availability, currency, or dress conventions matter; assume no country or currency.
