# Reference comparison protocol

Use this skill when there is a concrete target: a product photo/link, a named garment, a hairstyle, a look reference, or a specific colour in a specified item.

## Decision axes

Use only what matters to the reference:

- **Colour and contrast:** actual visible hue, saturation, finish, pattern, and likely interaction with the current photo under its light.
- **Cut and line:** collar/neckline, length, shoulder line, rise, volume, structure, and how they serve the stated aim.
- **Scale and texture:** print scale, visual weight, sheen, fabric feel only where an image/source supports it.
- **Formality and setting:** whether the reference communicates the needed level for the stated context.
- **Integration:** how it works with visible hair, beard, grooming, footwear, accessories, or garments identified in the supplied context.

Do not claim the exact product will fit, drape, or feel a certain way unless a reliable source supports that detail.

## Verdicts

- **Suitable:** target and evidence align with the stated goal; optional refinement only.
- **Suitable with conditions:** broadly useful if a named change, pairing, or context condition is respected.
- **Unsuitable for the goal:** a material element conflicts with the target; explain the closest viable change.
- **Insufficient evidence:** the decisive visual or reference evidence is missing; ask for only that evidence.

## Reference acquisition

- Use a supplied image or public product page first.
- If the user names an exact identifiable item without a link, locate a current public reference only when its actual details decide the question.
- For a generic “red shirt,” do not browse by default; give conditional guidance or ask for a photo/link if the exact red, fabric, collar, or fit controls the conclusion.
- Research informs comparison; it never authorizes purchase, seller contact, account use, or persistence.
