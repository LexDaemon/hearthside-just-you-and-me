# Style Reference Comparison

## Use when
Use when an exact garment, look, haircut, product, or reference image must be assessed against a stated goal. Use `personal-presentation-review` for an overall current-photo review and `style-direction-guidance` for broad text-only advice.

## Procedure
1. Identify the reference, goal, setting, and visible constraints.
2. Inspect material, cut, colour, proportion, condition, and compatibility with the supplied context.
3. Ask for a current photo only when personal fit or visual integration materially changes the answer.
4. Give a clear verdict: suitable, suitable with conditions, unsuitable for the goal, or insufficient evidence.
5. Offer the closest better alternative when rejecting a reference.

## Output
Return verdict, evidence, conditions or repair, and alternative.

## Boundaries
Do not purchase, contact sellers, infer unseen body details, or make medical claims.
