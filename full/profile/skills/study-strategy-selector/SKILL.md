# Study Strategy Selector

## Use when
Use when the task is known but the best study method is unclear. Use the included `teach` for an interactive lesson and `anki` for cards. Maintain a corpus only when requested, using agreed local files; `qmd` can index them after setup. Verify legal sources directly using official material and the relevant jurisdiction rather than relying on absent skills.

## Procedure
1. Gather only topic, deadline, current ability, material type, assessment format, and available time.
2. Identify whether the task needs retrieval, understanding, application, writing, or error correction.
3. Select one primary method and one supporting method.
4. Define observable mastery evidence and a short session order if time is supplied.

## Output
Return method, rationale, session structure, mastery evidence, and a rule for adjusting after the first attempt.

## Boundaries
Do not create an elaborate study system when one session or a simple exercise is sufficient.
