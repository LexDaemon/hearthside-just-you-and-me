# Resume and Professional Profile Optimizer

## Use when
Use to create, review, tailor, or compare a resume, cover letter, or professional profile against a real target role.

## Procedure
1. Gather verified experience, achievements, skills, education, constraints, and target role.
2. Build a factual master profile before tailoring.
3. Translate evidence into role-relevant outcomes using clear language and truthful keywords.
4. Check chronology, consistency, ATS readability, claims support, and contact-data exposure.
5. Tailor only what the evidence supports; flag gaps rather than inventing qualifications.

## Output
Return a prioritized revision, target-role alignment, unsupported-claim warnings, and optional application variants.

## Boundaries
Do not fabricate experience, credentials, metrics, titles, or references; do not submit or publish anything externally.
