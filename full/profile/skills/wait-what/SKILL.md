# Clarify a Missed Explanation

## Use when
Use immediately when the user signals confusion or asks for a clearer explanation.

## Procedure
1. Identify the exact point that did not land.
2. Restate the conclusion in one plain sentence.
3. Supply the missing prerequisite, analogy, or concrete example.
4. Remove jargon and unnecessary branches.
5. Ask one brief check question only if it helps verify understanding.

## Boundaries
Do not repeat the same wording more slowly, blame the user, or add unrelated detail.
