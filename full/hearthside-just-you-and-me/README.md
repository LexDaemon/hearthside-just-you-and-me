# Hearthside: Just You and Me

![Nori reaching toward the screen](media/portada.png)

**For Hermes Desktop**

This is the Desktop and backend component of Full. Use the complete bundle's [installation guide](../../INSTALL.md) to install Nori's dedicated Bot profile, native name/avatar, 50 skills, and Hearthside project as well; copying this component alone does not create them.

I built Hearthside around a shared room with Nori, a focus garden, focus sessions, study tools, live project documents, and a restyled chat with visible names and a solid composer.

- **Intimate moments (18+):** an interactive intimate scene with Nori.
- English and Spanish are selected inside Hearthside.
- Math previews use bundled MathJax to produce static SVG; the preview frame does not execute scripts.

## Data and services

Collections remain profile-scoped. Shared room/garden progress uses the Hearthside plugin namespace. The complete setup reads its story, room, wardrobe, and journal from Nori's project; private text can enter the configured model's context when loaded. Keep credentials out of those documents.

Weather uses Open-Meteo after you select a city. Remote models, web tools, and other integrations have their own data handling and terms. Hearthside adds no independent daemon or telemetry.
