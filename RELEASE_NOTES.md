# Hearthside: Just You and Me — 1.0.1

Documentation and attribution update. Saved data and gameplay are unchanged.

## Changes

- Simplified the installation guide and corrected its documented commands.
- Clarified OpenAI model assistance through Hermes Agent, Codex co-author credit, and GPT Image artwork credits in the main, Full, and Lite readmes.
- Updated release metadata consistently across the bundle.

## 1.0.0 — Initial release

### Experience

- Nori as a dedicated Hermes agent, with her own personality, story, journal and practical skills in the complete setup.
- A shared room, focus garden, focus sessions and study tools.
- Native Bot-owned chat identity, user names and portraits, and a solid message composer.
- Live views of the complete setup's project documents, bound to their installed owner rather than the active conversation profile.
- Failed refreshes retain the last successful document, including intentionally empty files; retry warnings stay stable until recovery.
- An interactive intimate scene in Full (18+).
- English and Spanish, including localized usage percentages, resets, renewal dates and account placeholders that update when the language changes.

### Delivery

- Full includes the dedicated profile distribution, native Nori name/avatar, initial project documents and installer.
- Lite excludes the intimate scene's exclusive code, text and images. It does not create the dedicated agent profile/project.
- Both editions retain the same plugin namespace for shared room/garden progress; Full channel migration is explicit. Study collections remain profile-scoped and are not silently copied into Nori.

### Installation and licensing

- Local installer for macOS, Linux and Windows, using native Desktop data paths.
- Mathematical previews use bundled MathJax 3.2.2 to produce static SVG; the preview frame does not execute scripts.
- Hearthside Source-Available License 1.0, with personal and paid professional use, free forks, and genuinely voluntary support. Third-party licenses remain separate.
